# 李富贵推送数据需求清单

## 一、大盘情绪计算（已实现）✅

### 推送接口
- **URL**: `POST https://a-stock.xyz/api/multifactor`
- **认证**: `Authorization: Bearer <PUSH_TOKEN>`
- **频率**: 交易时段每 5-10 分钟

### 必填字段（3 个）
| 字段 | 类型 | 说明 | 权重 |
|------|------|------|------|
| `total_volume` | number | 沪深总成交额（亿元） | M1 30% |
| `limit_up_count` | number | 涨停家数 | M4 20% |
| `limit_down_count` | number | 跌停家数 | M4 20% |

### 选填字段（5 个）
| 字段 | 类型 | 说明 | 权重 | 缺失处理 |
|------|------|------|------|----------|
| `rise_count` | number | 上涨家数 | M3 20% | 从 fall_count 推算 |
| `fall_count` | number | 下跌家数 | M3 20% | 从 rise_count 推算 |
| `turnover_rate` | number | 全市场换手率（%） | M2 20% | Tushare T+1 补齐 |
| `margin_balance` | number | 融资余额（亿元） | M5 10% | Tushare T+1 补齐 |
| `change_pct` | number | 较上次推送变化（%） | 趋势计算 | 自动计算 |

### 自动补齐字段（2 个）
| 字段 | 数据源 | 更新频率 | 说明 |
|------|--------|----------|------|
| `turnover_rate` | Tushare `daily_basic` | T+1 | 全市场换手率加权平均 |
| `margin_balance` | Tushare `margin` | T+1 | 沪深融资余额合计 |

## 三、推送方案建议

### 方案 A：最小化推送（当前已实现）
只推送大盘情绪所需的 3-8 个字段，其他数据从第三方 API 获取。

**优点**：
- 推送数据量小，实现简单
- 宏观经济数据变化慢，无需实时推送

**缺点**：
- 市场参考模块依赖第三方 API（可能有 CORS 问题）
- 海外股价需要额外数据源

### 方案 B：完整推送（推荐）
李富贵推送所有数据，包括情绪 + 宏观 + 产业链 + 海外股价。

**推送结构**：
```json
{
  // 大盘情绪（必填）
  "total_volume": 8000,
  "limit_up_count": 80,
  "limit_down_count": 10,
  "rise_count": 3000,
  "fall_count": 1500,
  "turnover_rate": 0.85,
  "margin_balance": 18000,
  
  // 宏观经济（选填，月度/季度更新）
  "macro": {
    "china": { "pmi": 50.5, "cpi": 0.3, "m2_growth": 7.2 },
    "us": { "fed_rate": 5.25, "cpi": 3.2, "unemployment": 3.7 }
  },
  
  // 海外股价（选填，实时/日终更新）
  "overseas": {
    "us": { "nvda": 120.5, "aapl": 175.3, "tsla": 250.8 },
    "jp": { "nikkei": 33500, "tel": 5800 },
    "kr": { "samsung": 72000 }
  }
}
```

**优点**：
- 数据统一，无需多个数据源
- 可以避免 CORS 问题
- 数据更新时机可控

**缺点**：
- 推送数据量较大
- 需要李富贵整合多个数据源

### 方案 C：混合推送（折中）
- 大盘情绪：李富贵实时推送（5-10 分钟）
- 宏观经济：李富贵日终推送（每天 1 次）
- 海外股价：前端直接调用第三方 API（如 Yahoo Finance、Alpha Vantage）

**优点**：
- 平衡推送频率和数据量
- 海外股价用成熟 API，数据质量高

**缺点**：
- 前端需要处理多个 API 调用
- 可能有 CORS 限制

## 五、技术实现建议

### 推送接口扩展
```typescript
// 扩展现有 /api/multifactor 接口
interface ExtendedPushData {
  // 现有字段（保持不变）
  total_volume: number;
  limit_up_count: number;
  limit_down_count: number;
  rise_count?: number;
  fall_count?: number;
  turnover_rate?: number;
  margin_balance?: number;
  
  // 新增字段（选填）
  macro?: {
    china?: MacroIndicators;
    us?: MacroIndicators;
    europe?: MacroIndicators;
    japan?: MacroIndicators;
    korea?: MacroIndicators;
  };
  
  overseas?: {
    us?: Record<string, number>;  // { nvda: 120.5, aapl: 175.3 }
    jp?: Record<string, number>;  // { nikkei: 33500 }
    kr?: Record<string, number>;  // { samsung: 72000 }
  };
}
```

### 数据存储
```sql
-- 宏观经济数据表
CREATE TABLE macro_indicators (
  id UUID PRIMARY KEY,
  economy VARCHAR(10) NOT NULL,  -- 'china', 'us', 'eu', 'jp', 'kr'
  indicator VARCHAR(50) NOT NULL, -- 'gdp_yoy', 'pmi', 'cpi'
  value DECIMAL(10,4) NOT NULL,
  period VARCHAR(10) NOT NULL,    -- '2024-01', '2024-Q1'
  created_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(economy, indicator, period)
);

-- 海外股价表
CREATE TABLE overseas_prices (
  id UUID PRIMARY KEY,
  market VARCHAR(5) NOT NULL,     -- 'US', 'JP', 'KR'
  symbol VARCHAR(20) NOT NULL,    -- 'NVDA', 'AAPL'
  price DECIMAL(10,2) NOT NULL,
  change_pct DECIMAL(6,2),
  updated_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(market, symbol)
);
```
