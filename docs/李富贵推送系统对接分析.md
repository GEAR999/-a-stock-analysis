# 李富贵推送系统对接分析

## 一、李富贵文档 vs 当前系统对比

### 1.1 推送接口对比

| 项目 | 李富贵文档 | 当前系统实现 | 差异 |
|------|-----------|-------------|------|
| URL | `https://47.122.115.203/api/multifactor` | `/api/multifactor` | ✅ 一致（IP 直连） |
| 认证 | `Authorization: Bearer <PUSH_TOKEN>` | `Authorization: Bearer <PUSH_TOKEN>` | ✅ 一致 |
| Host 头 | `Host: a-stock.xyz`（IP 直连时需要） | 未强制要求 | ⚠️ 需添加 |
| Content-Type | `application/json` | `application/json` | ✅ 一致 |

### 1.2 数据结构对比

#### 李富贵文档的统一推送结构：
```json
{
  "type": "sentiment" | "overseas" | "macro_china" | "macro_us" | "rate",
  "status": "available" | "pending" | "not_available",
  "message": "数据状态说明",
  "sentiment": { ... },
  "overseas": { ... },
  "macro_china": { ... },
  "macro_us": { ... },
  "rate": { ... }
}
```

#### 当前系统的数据结构：
```json
{
  "total_volume": 8000,
  "limit_up_count": 80,
  "limit_down_count": 10,
  "rise_count": 3000,
  "fall_count": 1500,
  "turnover_rate": 0.85,
  "margin_balance": 18000
}
```

**差异分析**：
1. ❌ 当前系统**没有 `type` 字段** — 只支持情绪数据推送
2. ❌ 当前系统**没有 `status` 字段** — 无法处理 pending/not_available 状态
3. ❌ 当前系统**没有 `message` 字段** — 无法传递状态说明
4. ❌ 当前系统**不支持海外股价**（`overseas`）
5. ❌ 当前系统**不支持宏观经济**（`macro_china`、`macro_us`）
6. ❌ 当前系统**不支持央行利率**（`rate`）

## 二、需要改造的内容

### 2.1 推送接口改造（高优先级）

**文件**：`src/app/api/multifactor/route.ts`

**改造内容**：
1. 添加 `type` 字段解析（sentiment/overseas/macro_china/macro_us/rate）
2. 添加 `status` 字段处理（available/pending/not_available）
3. 添加 `message` 字段存储
4. 根据 `type` 分发到不同的处理逻辑

**伪代码**：
```typescript
export async function POST(request: NextRequest) {
  const body = await request.json();
  const { type, status, message } = body;
  
  switch (type) {
    case 'sentiment':
      return handleSentiment(body.sentiment, status, message);
    case 'overseas':
      return handleOverseas(body.overseas, status, message);
    case 'macro_china':
      return handleMacroChina(body.macro_china, status, message);
    case 'macro_us':
      return handleMacroUs(body.macro_us, status, message);
    case 'rate':
      return handleRate(body.rate, status, message);
    default:
      return NextResponse.json({ success: false, error: '未知的 type' }, { status: 400 });
  }
}
```

## 四、关键问题

### 4.1 向后兼容性
**问题**：当前李富贵推送的是旧格式（没有 `type` 字段），改造后是否兼容？

**解决方案**：
```typescript
// 兼容旧格式
if (!body.type) {
  // 旧格式：直接是 sentiment 数据
  body.type = 'sentiment';
  body.sentiment = body;
}
```

### 4.2 数据缺失处理
**问题**：李富贵文档说 `turnover_rate` 和 `margin_balance` 可以不传，系统自动补齐。

**当前实现**：已经实现了 Tushare T+1 自动补齐逻辑 ✅

### 4.3 pending 状态处理
**问题**：宏观数据未到发布日时，`status=pending`，前端如何展示？

**解决方案**：
- 数据库存储 `status` 和 `message` 字段
- 前端查询时返回最新记录
- 如果 `status=pending`，显示"数据待发布：{message}"
